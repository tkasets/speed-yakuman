# スピード役満

配牌から、できるだけ早く役満を完成させるまでの秒数を競うブラウザゲーム。

- https://speedyakuman.t-kasets.com
- 素のHTML/CSS/JavaScript(ES Modules)。ビルド不要
- ローカル起動: `npx serve .` → http://localhost:3000
- テスト: `node --test`
